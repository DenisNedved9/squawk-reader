# Squawk Code Reader

Jednoduchá konzolová aplikace v jazyce C pro načítání a vyhledávání leteckých nouzových kódů (Squawků) z textového souboru.

## Jak to funguje
1. Program načte data ze souboru `squawks.txt`.
2. Vyzve uživatele k zadání hledaného kódu.
3. Porovná vstup a v případě shody vypíše detail z databáze.

## Použité technologie
- Jazyk C (práce se soubory, pole, řetězce)
